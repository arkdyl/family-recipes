# Family Recipes

This is a simple website, where I keep a few classic recipes, just so that they don't get lost.

## What is inside?
* A list of three simple dishes.
* Ingredients and step-by-step instructions for each one.
* Clean black-and-white design, that is easy to read and print.

## How do I open it?
You can access the page by opening https://arkdyl.github.io/family-recipes/ in your new tab. You can access it using any browser you want!
